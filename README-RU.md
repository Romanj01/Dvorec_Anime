# Дворец Аниме — демо для GitHub Pages

Автономный демонстрационный магазин в аниме-стилистике: 9 товаров, категории и подборки по сериям, избранное, корзина, личный кабинет и открытая админка с 12 учебными заказами. Telegram, VPS, база данных и ключи оплаты не нужны. Это отдельная копия, существующие магазины не изменяются.

## Посмотреть локально

С установленным Node.js выполните в этой папке:

```sh
node serve.mjs
```

Откройте `http://127.0.0.1:3183/dvorets-anime-demo/`. Админка: `http://127.0.0.1:3183/dvorets-anime-demo/#/admin/orders`.

## Опубликовать на GitHub Pages

1. Распакуйте архив и загрузите его содержимое в корень отдельного репозитория. `index.html`, `app.js`, `app.css`, `.nojekyll`, папки `assets` и `fonts` обязательны. Загрузка самого ZIP вместо файлов сайт не публикует.
2. Откройте **Settings → Pages → Deploy from a branch**.
3. Выберите `main`, папку `/ (root)` и сохраните.
4. Дождитесь публикации и откройте выданную GitHub ссылку.

Сборка уже включена, npm для публикации не нужен. Имя репозитория может быть любым: все ресурсы и hash-маршруты `#/…` работают в подпапке GitHub Pages.

## Что доступно клиенту

- Каталог: фигурки, манга, косплей и линзы; вложенные подборки «Чиби», «Тетрадь смерти», «Хвост феи», «Очень приятно, Бог»; поиск, сортировка, ценовые фильтры и страницы каталога.
- Карточки с галереей: у всех девяти обработанных товарных изображений вторым кадром показано исходное фото до ИИ-обработки. Размер в сантиметрах и точная модель этих фигурок неизвестны; это фигурки с обычными пропорциями, не утверждение о масштабе 1:1.
- Избранное, корзина, учебное оформление заказа и имитация оплаты, история покупок.
- Админка: товары, несколько категорий одному товару, флаг новинок, категории и подкатегории, предпросмотр и загрузка фото, CSV-импорт и экспорт.
- Статусы заказов, склад и резерв, возвраты, расходы, финансовые графики и журнал действий.
- Настройки оформления: цвета, логотип, баннер, заголовок и текст первого экрана. Две надписи поверх фото включаются независимо, выключение сохраняет текст, обе выключенные не оставляют пустую плашку.

Все изменения сохраняются **только в браузере текущего посетителя**, через IndexedDB с резервным localStorage. Общей серверной админки у GitHub Pages нет. «Сбросить демо» с подтверждением восстанавливает исходный пример. Реальные заказы, оплаты, сообщения магазину и отправления не выполняются.

Для изменения начального состояния для всех посетителей редактируйте `src/anime.json`, `src/seed-products.json` и при необходимости `src/initial-state.mjs`, пересоберите сайт и обновите файлы в репозитории. Существующие локальные изменения посетителя сохранятся до сброса демо; версию хранилища можно обновить в `namespace` файла `src/browser-api.ts`.

## Ассортимент и цены

Данные перенесены с предоставленных пользователем скриншотов ВК и двух фотографий фигурок. Цена относится к скриншоту и не подтверждает текущий прайс или наличие.

| Позиции | Цена на скриншоте |
|---|---:|
| Акаши Сейджуро, чиби-фигурка | 400 ₽ |
| «Хвост феи», тома 6, 8 | 450 ₽ за том |
| «Тетрадь смерти», том 4 | 450 ₽ за том |
| «Очень приятно, Бог», том 8 | 450 ₽ за том |
| M026-brown, M025-purple | 650 ₽ за позицию |

Для двух фигурок с обычными пропорциями названы только описания внешнего вида: «Мечница в белом» и «Тактический образ». Их точные названия, серия, производитель, масштаб и цена не предоставлены. **7 900 и 9 900 ₽ придуманы для показа корзины**. Не использовать эти суммы как предложение магазина.

Десять позиций без фотографий удалены из каталога: оставлены только товары с предоставленными изображениями. Верхняя полоса приглашает посмотреть витрину и попробовать управление магазином. Данные о наличии, себестоимости, клиентах, сотрудниках, заказах и финансах вымышлены.

Девять товарных изображений и логотип обработаны встроенным ImageGen. ИИ улучшил освещение, чёткость и фон, но может изменить мелкие детали, буквы и внешний вид. Это демо-изображения; для коммерческой публикации нужны согласованные оригиналы. Первый экран — отдельная художественная аниме-иллюстрация, а не реальное фото помещения. Промпты и происхождение сохранены в `IMAGE-PROMPTS.md` и `assets/image-processing.json`. Шрифт Manrope размещён локально, лицензия в `fonts/LICENSE-Manrope.txt`. Иконки — SVG.

## Разработка

```sh
npm install
npm run build
npm test
```

React 19, esbuild, browser-local API. `build.mjs` собирает `app.js`, `app.css` и используемые шрифты. Демо не содержит Telegram-токенов, платёжных ключей, паролей или конфигурации VPS.
